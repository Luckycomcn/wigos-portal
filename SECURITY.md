# Security policy

## Supported versions

This project is a demonstration application. Security fixes target the latest code on the default branch. Older snapshots are not maintained; update to the latest revision.

## Reporting a vulnerability

Do not disclose exploitable vulnerabilities or credentials in public issues. Use GitHub's **Report a vulnerability** option under the repository Security tab when available. Otherwise contact the repository owner privately through the contact methods on newoscar_cma@163.com to arrange a private report.

Include the affected revision, reproduction steps, impact and a proposed fix if available. Remove unrelated personal data and secrets. Maintainers will assess the report and coordinate a fix and disclosure with the reporter. Response times depend on maintainer availability.
